📲 Already have LifeOS? You don’t need this page — open the app → Settings → App & updates → Download & install. New versions also show up there by themselves.

First-time install

  1. Tap Download APK above and open the file when it finishes.
  2. If Android asks, allow Install unknown apps for your browser (one time).
  3. Tap Install. Done — from now on updates install from inside LifeOS.
If Android says “App not installed” or “conflicts with an existing package”, an older LifeOS signed with a different key is installed. Sync / back up your data, uninstall that old app once, then install this one.
